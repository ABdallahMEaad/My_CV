# 🏗️ Automation Framework Architecture

```text
SwagLabs
│
├── src
│   ├── main
│   │   └── java
│   │       ├── DriverFactory
│   │       ├── Page
│   │       │   ├── BasePage
│   │       │   ├── LoginPage
│   │       │   └── ProductsPage
│   │       └── Data
│   │
│   └── test
│       └── java
│           └── TestCases
│               ├── LoginTest
│               └── AddToCartAndCheckout
│
├── pom.xml
├── testng.xml
└── README.md
```

### Design Pattern

The automation framework follows the **Page Object Model (POM)** to improve:

* Maintainability
* Reusability
* Readability
* Scalability
* Separation of concerns
